§4 · Attraction Principles Applied
HOOK FIRST
resonance: 자막 +1.0s / KB 0.3x / 5s
attraction: 자막 +0.3s / KB 0.4x / 4s
첫 프레임에서 자막을 즉시 노출. 0.3초 안에 카피가 등장해 스크롤을 멈추게 한다. 운동감도 약간 증가해 시선을 잡는다.
PACING FASTER
resonance: 30s / F1–F4 각 5s
attraction: 21s / F1 4s / F2–F4 각 3s
전체 9초 단축. F2/F4 breathing gap을 5s→3s로 압축. DreamTown의 감정 여운은 최소 3s 유지 — 완전히 제거하지 않는다.
SUBTITLE STRONGER
resonance: opacity 0.7 / thin
attraction: opacity 0.9 / regular
같은 카피(#9/#11/#2)를 더 선명하게. opacity 0.9 + regular weight로 작은 모바일 화면에서도 즉시 읽힌다.
CURIOSITY ENDING
resonance: F5 = closure / 10s
attraction: F5 = open ending / 8s
resonance에서 F5는 긴 여운으로 감정을 닫는다. attraction에서 F5는 8s로 약간 짧게 끊어 "이게 뭔지 더 보고 싶다"는 느낌을 만든다. 안개 속 항구 + '남았어요' = 열린 결말.
MOTION TIGHTER
resonance: Ken Burns 0.3x
attraction: Ken Burns 0.4x
Ken Burns를 0.3x→0.4x로 소폭 증가. dissolve를 1.0s→0.7s로 단축. 과장 없이 약간 더 역동적인 흐름. SSOT 상한(0.5x) 이하 유지.
CONTINUITY MAINTAINED
resonance: DreamTown 세계관
attraction: 동일 유지
동일 프레임 · 동일 카피 · 동일 감정 호 · Sowoni 뒷모습 원칙 · 금지 효과 없음. channel이 다를 뿐 DreamTown의 감정과 세계관은 변하지 않는다.
§5 · Viewer Intent — 시청자 경험 목표
◯ W1-v3  Resonance — Memory
  • 30초를 끝까지 보고 나서 감정이 남아있다
  • 오늘의 피로를 잠시 내려놓은 느낌이 든다
  • 자막이 조용히, 천천히 등장해서 부담 없다
  • 끝난 뒤 화면을 닫아도 여운이 계속된다
  • 다음에 또 보고 싶다는 생각이 든다 (재방문)
◈ W1-S  Attraction — Curiosity
  • 첫 1초 안에 "이게 뭐지?"라는 반응이 생긴다
  • 21초가 짧아서 끝까지 보게 된다
  • 끝나는 순간 "저장해야지"라는 생각이 든다
  • 카페와 항구 전환이 시각적 놀라움을 준다
  • 계정 팔로우 또는 원본 콘텐츠 탐색으로 이어진다
