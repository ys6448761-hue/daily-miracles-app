───────────────────────────────────────────────────────────────────────────────
SECURITY HIGHLIGHTS
───────────────────────────────────────────────────────────────────────────────

Token Generation:
- 32-byte (256-bit) crypto.randomBytes() secure random
- Unique per call (tested)
- 64-character hex encoding (no ambiguous characters)

Token Hashing:
- SHA256 (no salting needed for one-time use tokens)
- Deterministic (tested: same input → same hash)
- One-way (cannot reverse hash to get plaintext)

Token Validation:
- crypto.timingSafeEqual prevents timing attacks
- Constant-time comparison regardless of mismatch position
- No side-channel leaks

Cookies:
- httpOnly: Cannot be accessed by JavaScript (XSS protection)
- secure: Transmitted over HTTPS only (prod)
- sameSite=strict: No cross-site CSRF attacks

Storage:
- EXIF removal via Sharp (privacy)
- NODE_ENV check prevents accidental local storage in production
- Error on production without explicit ALLOW_LOCAL_STORAGE override
