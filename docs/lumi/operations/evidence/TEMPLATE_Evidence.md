# Evidence

Evidence는 여러 Observation을 연결하는 운영 근거이며, Candidate 승격의
근거다. Observation 하나만으로는 Evidence가 되지 않는다 — 반복된 패턴을
묶어야 한다. Evidence는 아이디어가 아니다.

## Evidence Type

다음 중 선택한다.

- Behavioral
- Emotional
- Preference
- Operational
- Knowledge
- Growth

## Related Observations

(이 Evidence를 구성하는 Observation ID 목록 — 최소 2개 이상 권장)

- `observations/OBS-...`
- `observations/OBS-...`

## Supporting Observation Count

예시: `3 Observations`, `7 Observations`, `12 Observations`

## Common Pattern

(연결된 Observation들에서 공통으로 나타나는 패턴이 무엇인가)

## Supporting Examples

(패턴을 뒷받침하는 구체적 사례 — 대화 요약이 아니라 관찰된 사실 기준)

## Contradicting Evidence

이 Evidence와 상충하는 Observation이 있다면 함께 기록한다. 없으면
`None`.

## Confidence

Evidence 전체의 신뢰 수준.

| 등급 | 기준 |
|---|---|
| ★★★★★ | 반복적으로 확인된 패턴 |
| ★★★★☆ | 여러 사례에서 확인 |
| ★★★☆☆ | 관찰은 되었지만 추가 검증 필요 |
| ★★☆☆☆ | 단일 사례 |
| ★☆☆☆☆ | 가설 수준 |

## Next Validation

다음에 무엇을 확인해야 하는지 기록한다.

- 추가 사용자 검증
- 다른 사용자 그룹 비교
- 반복 여부 확인
- 장기 추적
