# _pilot-test-samples/

---

**목적:** `TEMPLATE_Highlight.md`가 실제로 작동하는지 검증하기 위한
**가상 데이터**를 보관한다.

**⚠️ 이 폴더의 내용은 실제 운영 데이터가 아니다.** 실제 소원이와의 대화에서
나온 것이 아니라, 템플릿 검증용으로 작성된 샘플이다. `Conversation
Reference`도 전부 `TEST-CONV-*`로, 실제 대화 ID가 아니다.

**사용 원칙:**

- 이 폴더의 Highlight를 근거로 실제 `observations/`에 Observation을
  작성하지 않는다 — 가상 데이터이므로 운영 근거가 될 수 없다.
- 실제 파일럿 운영이 시작되면, 진짜 Highlight는 `highlight/` 바로 아래에
  (이 하위 폴더가 아니라) 저장한다.
- 이 폴더는 템플릿 형식이 실제로 채워질 때 어떤 모습인지 확인하는
  용도로만 유지한다.
