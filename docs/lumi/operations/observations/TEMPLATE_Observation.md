# Observation

Observation은 "대화 요약"이 아니라 운영 관찰이다 — 무엇을 발견했는지,
왜 중요한지, 재현 가능한지를 기록한다. Observation은 Conversation을
직접 요약하지 않는다 — `highlight/`에 쌓인 Highlight를 분석하여
작성한다.

## 생성 기준

Observation은 Highlight가 충분히 축적된 이후에만 작성한다.

권장 기준:

- 동일 유형 Highlight 3~5개 이상
- 반복성 확인
- 운영 의미 확인

## Related Highlights

(이 Observation의 근거가 된 `highlight/` 항목 ID 목록)

- `highlight/HL-...`
- `highlight/HL-...`

## Observation Type

다음 중 하나를 선택한다.

- Behavior
- Emotion
- Preference
- Growth
- Operation
- Knowledge
- Communication
- Other

## Frequency

현재까지 몇 번 관찰되었는지 기록한다.

예시: `1회`, `3회`, `7회`, `15회`

## Validation Status

다음 중 하나를 사용한다.

- Observation
- Emerging Pattern
- Validated Pattern
- Candidate Ready

## Confidence

Observation의 신뢰 수준을 기록한다. 판단 기준도 함께 작성한다.

| 등급 | 기준 |
|---|---|
| ★★★★★ | 반복적으로 확인된 패턴 |
| ★★★★☆ | 여러 사례에서 확인 |
| ★★★☆☆ | 관찰은 되었지만 추가 검증 필요 |
| ★★☆☆☆ | 단일 사례 |
| ★☆☆☆☆ | 가설 수준 |
