## §5 Zone 1 PROVISIONAL 경계 시안 (overview 이미지용)

**경계 정의**: 원도심 해안권 탐색 범위. 행정구역 경계 아님. 점선 표시.

**PROVISIONAL 폴리곤 좌표** (overview, 추정 기반, 고불확실도):

```js
// Zone 1 boundary — PROVISIONAL (검증되지 않은 추정)
// 실제 이미지 calibration 후 수정 필요
points: [
  { x: 0.18, y: 0.35 },  // NW: 이순신광장 북서
  { x: 0.45, y: 0.32 },  // N:  종포해양공원 북측
  { x: 0.50, y: 0.42 },  // NE: 종포해양공원-하멜등대 중간
  { x: 0.48, y: 0.60 },  // SE: 하멜등대 동남
  { x: 0.35, y: 0.65 },  // S:  낭만포차거리 남측
  { x: 0.18, y: 0.52 },  // SW: 이순신광장 남서
]
```

**시각적 설명**:
```
이미지 내 예상 위치 (개략):

  [0.18,0.35]---[0.45,0.32]
       |                  |
       |   Zone 1          [0.50,0.42]
       |   원도심              |
  [0.18,0.52]              [0.48,0.60]
       |                  |
       \---[0.35,0.65]-----/

* NW-SW 경계: 이순신광장 서쪽 해안
* NE-SE 경계: 하멜등대·종포해양공원 동쪽
* 북쪽: 항만 시설 포함
* 남쪽: 낭만포차거리 남쪽까지
```

**불확실 구간**:
- 북쪽 경계: 종포해양공원 북쪽 한계 미확인 (항만 시설 포함 여부)
- 서쪽 경계: 이순신광장 서쪽 범위 미확인
- 남동 경계: 하멜등대와 돌산대교(Zone 3) 사이 정확한 경계 미확인

## §7 현재 코드 상태

현재 모든 Zone의 `boundary.status = 'UNVERIFIED'` → SVG 미렌더링. 사용자 화면 변화 없음.

PROVISIONAL 시안을 개발 환경에서 보려면:
```js
// yeosuMapData.js — Zone 1 (임시 개발 확인용, 서비스 배포 전 UNVERIFIED 복구 필수)
boundary: {
  imageId: 'yeosu-overview-v01',
  points: [
    { x: 0.18, y: 0.35 }, { x: 0.45, y: 0.32 }, { x: 0.50, y: 0.42 },
    { x: 0.48, y: 0.60 }, { x: 0.35, y: 0.65 }, { x: 0.18, y: 0.52 },
  ],
  status: 'PROVISIONAL',  // ← 사용자 화면 미표시, 개발 확인 전용
  source: 'estimated-2026-10-26 (geographic-coord-to-image mapping, HIGH uncertainty)'
}
```

**Founder 검수 방법**:
1. 개발 환경에서 `status: 'PROVISIONAL'`로 임시 설정
2. 코드에서 PROVISIONAL도 렌더링하도록 임시 변경 (`boundary?.status === 'PROVISIONAL' || ...`)
3. `localhost:5100/muyojeong` → 지역별 보기 → (Zone 1 overview hover 또는 Zone 3~7 ZoneDetail overview 표시 확인)
4. 경계 위치 피드백 → 좌표 수정 → 반복
5. Founder 승인 → `status: 'VERIFIED'` 승격 → 실 서비스 표시
