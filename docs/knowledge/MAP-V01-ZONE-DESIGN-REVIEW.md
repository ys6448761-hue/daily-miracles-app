## §7 권역 설계 추가 고려사항

### 케이블카의 귀속 문제

현재 Zone 2. 케이블카는 지리적으로:
- 원도심 쪽 정류장: 돌산해협 본토 편 (오동도 방면)
- 돌산 쪽 정류장: 돌산도 북부 (돌산공원 인근)

→ 케이블카 자체는 "원도심↔돌산 연결 경험"으로 SOUL이 이해. Zone 귀속보다 경험 특성이 중요.

**권고:** 케이블카는 Zone 귀속보다 SOUL knowledge(`cablecar` Phase 1 완료)에 맞게 유지. 권역 이동 시 SOUL API 점검 필요.

### 향일암 단독 권역 유지 근거

- 향일암은 "일출"이라는 시간 조건 특수성이 있음 (이른 아침 방문, 일반 SOUL 추천 흐름과 다름)
- 돌산공원(야경)과 같은 권역으로 묶으면 "일몰야경+일출"의 상충 이미지
- 단독 권역으로 분리하면 나중에 "향일암 일출 특수 SOUL 경험" 별도 설계 가능

**권고:** 향일암은 단독 Zone 유지 (1곳이어도 여행 경험상 독립성 가치 있음)

### Zone 5·6·7 TG_READY 0개 문제

현재 이 Zone들은 "장소 탐색 가능" UI로만 기능.
- UI 개선: "코스 추천 0곳" 배지 대신 "탐색 중" 배지로 표시 변경
- 데이터 개선: VERIFY 중 1-2개를 EXPLORER로 승격 (별도 검증 후)
