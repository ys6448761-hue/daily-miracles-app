## 핵심 선언

> 세계는 숨 쉬지만 사람은 기억처럼 머문다.

이 한 문장이 DreamTown Presence의 전체 규칙이다.

---

## 살아있는 것 / 머무는 것

### 살아있는 것 (Alive)

```
하늘   — 빛의 밀도가 미세하게 변한다
물     — 조용히 출렁인다
빛     — 맥박처럼 강약이 있다
공기   — 그레인, 분위기, 숨결
별     — 조용히 깜박인다
```

### 머무는 것 (Still)

```
사람     — 공기에 의해 미세하게 영향받을 뿐. 스스로 행동하지 않는다.
건물     — 고정
카메라   — 관찰자처럼 아주 조금 숨 쉴 뿐
```

---

## 세계가 살아나는 방식

세계는 항상 움직이지 않는다.

정적이 있고, 그 안에서 조용히 깨어나는 순간이 있다.

```
정적 → 깨어남 → 공명 → 잔향 → 다시 정적
```

이 사이클이 Presence의 시간 단위다.
레이어들은 동시에 켜지지 않는다. 차례로 살아난다.

---

## 사람에게 허용되는 것

공기가 사람을 통과하는 방식:

```
손끝의 아주 작은 떨림
컵을 쥔 손이 서서히 이완되는 것
옷소매가 공기에 조금 밀리는 것
바람이 머리칼을 아주 조금 움직이는 것
```

판단 기준:
> "공기 때문에 아주 조금 흔들린다. 공간이 감정을 기억한다."

---

## 절대 금지

사람이 하면 안 되는 것:

```
시선 이동
표정 변화
고개 돌림
손짓 / 제스처
입술 움직임
감정 연기
```

카메라가 하면 안 되는 것:

```
빠른 팬
드론 무빙
핸드헬드 흔들림
틱톡 스타일 움직임
피사체를 향한 줌
극적 동기화
```

판단 기준:
> "저 사람이 살아서 행동한다. 저가 AI 영상 느낌."

이렇게 느껴지면 Drift다.

---

## 카메라는 관찰자다

카메라는 드라마를 만들지 않는다.

허용:
```
감정이 깊어지는 순간 아주 미세한 확대
관찰자의 숨결 같은 옆으로의 미동
잔향 단계의 조용한 후퇴
```

이 모든 움직임은 감지되지 않을 만큼 작아야 한다.
느껴지는 순간 이미 과하다.

---

## 모든 조합 선생성 금지

Presence는 미리 만들어두는 것이 아니다.
필요한 씬에서, 필요한 감정으로, 그때 만든다.
