## 위치

감정은 UI 상태가 아니다. 감정은 공기의 밀도다.

이 문서는 DreamTown이 감정을 시각 언어로 번역하는 규칙을 정의한다.
감정이 기술을 이끈다. 기술이 감정을 만들려 해서는 안 된다.

---

## 감정 5종

### confusion — 혼란

```
이 순간의 질감:
  무엇인지 모르겠는 무게
  안개 속에서 무언가를 찾는 중

시각 언어:
  별:   안개 너머 아주 멀리, 아직 보이지 않음
  빛:   흐릿, 방향 없음
  공기: 두껍고 조용함
  색:   짙은 청회색, 낮은 채도

금지:
  밝아지려는 움직임
  해결을 암시하는 전환
  강한 색채
```

---

### pause — 멈춤

```
이 순간의 질감:
  숨을 고르는 중
  아직 무언가를 결정하지 않은 사이

시각 언어:
  별:   아주 조금 보이기 시작함, 조용한 존재감
  빛:   낮고 안정적
  공기: 고요함
  색:   어두운 청색 계열

금지:
  에너지가 상승하는 전환
  희망을 예고하는 빛
  빠른 템포
```

---

### calm — 고요함

```
이 순간의 질감:
  아무것도 바라지 않는 상태
  이 순간이 충분함

시각 언어:
  별:   조용히 탄생 중, 부드러운 빛
  빛:   균형 잡힌, 따뜻하지 않음
  공기: 맑고 고요함
  색:   깊은 야청색

금지:
  희망 또는 위안으로의 이동
  따뜻한 색채 침범
  정착한 느낌 — calm은 '아직 시작 전'의 상태
```

---

### curiosity — 호기심

```
이 순간의 질감:
  알고 싶다는 가벼운 기울어짐
  결심 전의 탐색

시각 언어:
  별:   가까워지고 있음, 위를 향한 방향감
  빛:   조금 더 선명해짐
  공기: 가벼워짐
  색:   청자색에서 라벤더 방향

금지:
  도착 느낌 — curiosity는 여전히 탐색 중
  결심이나 확신을 암시
  과한 밝기
```

---

### fragile_hope — 연약한 희망

```
이 순간의 질감:
  믿고 싶지만 아직 확신하지 못함
  조심스럽게 손을 뻗는 중

시각 언어:
  별:   가까이 왔지만 아직 완성되지 않음
  빛:   위를 향한 빛의 흔적
  공기: 라벤더, 조용한 상승감
  색:   새벽 직전 하늘

금지:
  별이 도착하거나 완성됨
  태양/일출 암시
  폭발적 확장
  용기나 결심으로의 전환
```

---

## 감정 간 관계

```
confusion ── pause ── calm
                        │
                    curiosity
                        │
                 fragile_hope
```

이 흐름은 하나의 가능한 경로다.
사람은 어디서든 시작할 수 있고, 순서대로 흐르지 않는다.

세계는 이 경로를 강제하지 않는다.
다만 각 감정이 머물 수 있는 공기를 정확히 담아낸다.

---

## 영상 아크 원칙

소원이 별이 되는 여정에서:

```
출발:  소원의 감정 (confusion일 수도, pause일 수도 있다)
호흡:  세계가 숨 쉬는 빈 순간 (두 번)
도착:  fragile_hope — 항상 조심스러운 상승이지, 도착이 아니다
```

F5(마지막 프레임)는 언제나 fragile_hope다.
완성된 희망이 아니라 여전히 손을 뻗는 중이다.

## 모든 조합 선생성 금지

감정은 미리 만들어두는 것이 아니다.
필요한 순간에, 필요한 하나만 만든다.
