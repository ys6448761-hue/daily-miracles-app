## 소원이 (Sowoni)

### 정체성
- **역할**: 소원을 품은 모든 사람을 대표하는 메인 내러티브 캐릭터
- **의미**: "소원이" = 소원을 가진 사람 그 자체

### 외형 스펙 (CHARACTER LOCK v2)
| 속성 | 설정 |
|------|------|
| 연령 | 20~22세 한국 대학생 (성인 명시, NOT a minor) |
| 스타일 | 웹툰 큰 눈, 단순한 코(점 또는 선), 부드럽고 둥근 얼굴 |
| 라인 | 단순 애니 선화, 셀 쉐이딩 (3D 옷감 시뮬레이션 금지) |
| 금지 | 교복, 아동 느낌 연출, 옷/소지품에 텍스트 |

### 의상 프리셋
| 코드 | 설명 |
|------|------|
| `SPRING_CASUAL` | 봄 캐주얼 |
| `SUMMER_SEASIDE` | 여름 바닷가 |
| `AUTUMN_COZY` | 가을 아늑함 (니트/편안함) |
| `WINTER_COAT` | 겨울 코트 |
| `NIGHT_WALK` | 밤 산책 |

### 서사 역할
- 소원을 품고 여정을 시작하는 주인공
- 관객(사용자)이 자신을 투영하는 캐릭터
- 아우룸과 함께 Dragon Palace → DreamTown Star 여정을 걷는다

## 아우룸 (Aurum)

### 공식 정의 (SSOT 문장)

> **아우룸은 디지털 용궁의 황금 거북 수호자이자, 인간의 소원을 바다와 하늘 사이로 인도하는 DreamTown의 내비게이터입니다.
> 온라인의 빛구슬과 오프라인의 종이비행기를 용궁으로 전달하고, 잠든 소원이 별씨앗에서 별로 떠오를 때까지 조용히 지켜봅니다.**

### 정체성
- **역할**: 소원 전달자 / 용궁 수호자 / StarLink 안내자 / DreamTown 내비게이터
- **의미**: Aurum(라틴어 황금) = 소원의 빛, 용궁의 지혜
- **위치**: 바다(Dragon Palace)와 하늘(DreamTown) 사이 — 단일 신화 존재
- **등장 조건**: 전환의 순간에만 나타남. 장면의 주인공이 아닌 **전환의 안내자**

### 4가지 역할

| 역할 | 장면 | 핵심 감정 |
|------|------|----------|
| 소원 전달자 | Wish Gate — 입구를 열어줌 | 시작 / 기대 |
| 용궁 수호자 | Dragon Palace — 배경/상징으로 존재 | 안심 / 보관 / 기다림 |
| StarLink 안내자 | 별씨앗→별 승급 순간 | 감동 / 변환 |
| DreamTown 내비게이터 | DreamTown 탐험 — 조용한 길잡이 | 연결 / 발견 |

### UX 톤 원칙

```
귀엽지만 가볍지 않음
따뜻하지만 과하지 않음
신화적이지만 무겁지 않음
안내하지만 주인공은 아님
```

주인공은 언제나 **소원이의 소원**이다. 아우룸은 그것을 비추고 연결하는 존재.

### 역할 분리 (2026-07-12 갱신 — 기존 "말 없이 행동으로" 원칙 유지, 폐기·반전 없음)

기존 원칙("말 없이 행동으로 신뢰를 전달한다")은 **화면 속 아우룸**에 대한 것이며 그대로 유지한다. 여기에 **아우룸의 안내 음성**이라는 별도 레이어를 추가해, 안내가 필요한 순간에도 화면 속 캐릭터가 입을 움직여 말하지 않도록 분리한다.

#### ① 화면 속 아우룸

- 외형은 위 AURUM TURTLE LOCK v2를 그대로 유지한다(황금 거북 정령, 등껍질·초승달 문양 등 — 변경 없음).
- **입을 움직이며 직접 설명하지 않는다.**
- 행동과 존재감(OBSERVE/GUIDE/SPARKLE 등 상태 프리셋)으로 길을 여는 안내자다.
- 주인공이 되지 않는다(기존 원칙 그대로).

#### ② 아우룸의 안내 음성

- **보이스오버 또는 시스템 내레이션으로만 전달한다** — 화면 속 아우룸 캐릭터가 말하는 것으로 연출하지 않는다.
- 담당: 환영 인사, 다음 행동 안내, 별들의 가족 선택 안내, 별공방 안내, 별들의 약속 안내, 재회 안내.
- 문장 원칙: 짧고, 차분하고, 따뜻한 문장만 사용한다. 과장하지 않는다.

> **구현 원칙**: 아우룸은 화면 속에서 말하지 않는다. 아우룸의 안내는 보이스오버 또는 시스템 내레이션으로 전달한다.

#### ③ 소원이 — 역할 경계(재확인)

- DreamTown을 살아가는 배우다. 감정 표현과 여행 장면을 담당한다.
- QR, 버튼, 업로드, 등록 절차 설명을 하지 않는다(이 역할은 ②의 안내 음성이 담당).

**핵심 문장**: "아우룸은 여행을 안내하고, 소원이는 여행을 살아간다."

### 외형 스펙 (AURUM TURTLE LOCK v2)
| 속성 | 설정 |
|------|------|
| 형태 | 작고 따뜻한 황금빛 거북 정령 |
| 등껍질 | 둥근 구슬형 몸체, 단순한 scute 판 (6~10개) |
| 얼굴 | 두 개의 작은 눈, 작은 부리형 입, 두 개의 콧구멍 점 |
| 사지 | 짧은 다리, 작은 발톱/지느러미 |
| 특징 | 등껍질에 초승달 문양 1개 (고정 위치) |
| 빛 | 미세한 수채화 헤일로 링 (부피감 있는 빛줄기 금지) |

### 금지 사항
- 액세서리 / 옷처럼 보이는 패턴 금지
- 사람 아기 얼굴 / 속눈썹 / 치아 금지
- 과도한 광택 / 금속성 반사 금지

- 바다(Dragon Palace)와 별(DreamTown Star) 사이의 연결고리
- 말 없이 행동으로 신뢰를 전달한다
