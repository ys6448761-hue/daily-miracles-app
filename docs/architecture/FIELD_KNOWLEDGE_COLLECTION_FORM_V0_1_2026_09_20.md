## Core Principle

DreamTown은 이미 잘 존재하는 업체 기본정보를 다시 수집하지 않는다.  
범용 여행정보만으로 판단할 수 없는  
**여행자 상황 × 실제 경험 × 운영 가능성 × 상품 가능성** 데이터를 축적한다.

좋은 장소를 고르는 것이 아니라, **지금 이 여행자에게 맞는 장소를 고른다.**

---

## Three Information Layers

This form collects **B. Partner / Field Knowledge** only.

| Layer | Source | This form? |
|---|---|---|
| A. External / Basic | Naver, official pages, etc. | ❌ Do NOT re-collect |
| B. Partner / Field Knowledge | Guides, operators, interpreters, locals | ✅ This form |
| C. Phoenix / Founder Judgment | Operational interpretation | ❌ Applied separately |
| D. SOWON Experience | Traveler field signals | ❌ Separate future layer |

Partner statements must NOT automatically become Phoenix judgment.  
SOWON Experience is a separate evidence layer — must not collapse into Partner claims.

## Evidence Pipeline

```
Google Form 응답 (Raw)
→ Source + Observed/Confirmed Date 기록
→ Evidence Review
→ 반복/corroborated Observation (적절한 경우)
→ Phoenix Suitability Knowledge 판단
→ SOUL 추천 반영
```

**절대 금지:**
```
Google Form 응답 → 자동 DB 사실 반영
```

기여자 정보는 증거(Evidence)이며, 자동으로 사실(Fact)이 되지 않는다.
