## 소원그림 2컷 구조

차이값 규칙: 좋은 그림→더 좋은 그림 ❌ / 고요한 세상→응답한 세상 ✅
셔플 테스트: 두 컷을 섞어도 즉시 구별되는가? NO = 실패.

**CUT1 소원그림 (사람 중심·고요)**
구도 격리: 원본 사진 구도 무시. selfie angle·framing·pose 버리고 DreamTown 구도로 재구성.
인물 45~55% / 세상 응답 10~20% / 해 없음·빛 고요·세상 정지.

**CUT2 기적이미지 (세상 중심·응답)**
인물 30~40% / 세계 60~70% / 인물 변화 0~5% / 세상 변화 95~100%.
응답 순서(고정): 별→하늘→구름→노을→바다→꽃→나무→사람
금지: 나이 변경·시간점프·미래 예언·다른 장소.

3대 Lock: Identity(사람) / Location(이야기, CUT1·CUT2 반드시 같은 장소) / World Response(세상)

## 수채화 시그니처 v3 — 얼굴 3D 금지

DreamTown은 수채화 먼저. AI 초상화 아님.
❌ 수채화 필터 AI 일러스트 / ❌ 반사실주의 캐릭터 / ❌ **3D 렌더링 얼굴**

얼굴 3D 방지: 코=수채 터치 1~2획 / 눈=캐치라이트 과잉 금지 / 볼턱=핑크 수채 번짐 / 피부=종이 질감 투과 필수. 조각·CGI 같으면 즉시 재생성.

```
FACE: Do NOT render as 3D. Paint as watercolor — flat washes, soft edges.
Paper texture must show through the skin.
```

목표: 웹툰 40% + 수채화 40% + 사실주의 20%
`2D illustration, hand-painted watercolor, visible paper texture, cel-shaded outlines,
Korean webtoon proportions, no 3D shading on face, watercolor washes on skin`

## 0단계 사진 체크 → QC 5문항 → 멈춤 규칙

**0단계:** 얼굴 너무 작음·단체 식별불가·역광·가림·흔들림·정면 정보 부족 → 생성 0회, 즉시 재요청

**QC 5문항:**
Q1. 본인으로 보이는가?
Q2. 표정이 '좋은 날의 눈빛'인가? (+관계의 온도)
Q3. 여수 오리진·보석별이 살아 있는가?
Q4. 캡션 없이 CUT1→CUT2가 응답 전→후로 보이는가? ← **최종 판단**
Q5. 안전영역 얼굴·별 잘리지 않는가?

출고: S급 5/5 / A급 4/5(Q1+Q4 PASS 필수) / 그 외 CEO 검토 큐

**3·2·1 멈춤:** CUT1 ≤3회, CUT2 ≤2회, 총 ≤5회. 같은 문항 2연속 NO → 원인별 분기(Q1=사진 재요청). Q1 실패=하드 게이트. "캡션 없이도 응답한 것이 보이는가?" YES 아니면 실패.
