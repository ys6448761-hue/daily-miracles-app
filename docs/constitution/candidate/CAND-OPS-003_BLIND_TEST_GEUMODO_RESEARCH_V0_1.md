1. Executive Summary

금오도 비렁길은 전라남도 여수시 남면에 위치한 섬(금오도) 위에 조성된 해안 절벽 트레일 시스템이다. 총 5개 코스, 공식 18.5km. "비렁"은 여수 사투리로 "벼랑(절벽)"을 의미한다.

핵심 구조적 특성: 비렁길은 단순한 장소(Place)가 아니라 섬 전체를 관통하는 이동 경험(Route + Movement Experience)이다. 여객선 접근, 코스 선택, 체력 관리, 귀항 시간 계획이 하나의 연속된 여정 구조를 형성한다.

주요 Research 발견:
- 공식 소요시간과 실제 소요시간 사이에 반복적이고 유의미한 격차 존재
- 코스별 거리 수치 출처 간 상충 존재 (CONFLICT 등록)
- 여객선 결항이 접근 자체를 차단하는 구조적 변수
- 날씨(강풍)가 트레일 안전에 직접 영향
- 동행자 체력 차이가 경험 전체를 좌우하는 주요 변수
- 계절별 자연 경관 차이 명확 (동백/가을 낙조)
- 장애인/휠체어 접근성 매우 제한적

5. Working Experience Identity — NOT FINAL

현재 Evidence 기반 가설:

▎ 금오도 비렁길은 섬 접근 여정 + 절벽 위 이동 경험 + 신체적 도전 + 극적인 해안 조망이 연속적으로 결합된 Movement Experience다.

- "비렁길을 간다"는 것은 특정 장소 방문이 아니라 섬에 들어가서 하루를 걷는 경험 전체를 의미한다.
- 도착 즉시 경험이 시작되지 않는다 — 여객선 탑승 → 섬 도착 → 코스 선택 → 걷기 시작의 준비 구조가 있다.
- 체력 소진과 경관의 극적 아름다움이 동시에 진행된다.
- "어디를 갔다"보다 "얼마나 걸었다 / 어떻게 완주했다"가 중심 경험이다.

이것은 가설이다. Founder Review 이전에 확정하지 않는다.

14. Place / Route / Movement Analysis

분석 결론:

금오도 비렁길은 다음 세 가지 유형이 결합된 복합 구조다.

Route (경로):
- 함구미 → 두포 → 직포 → 학동 → 심포 → 장지의 선형 Route 구조
- 코스별 진입/하산 분기점 존재
- 여러 독립 마을과 선착장을 연결

Movement Experience (이동 경험):
- 트레일을 걷는 과정 자체가 핵심 경험
- 걷는 동안 절벽, 바다, 숲이 연속적으로 펼쳐지는 이동 중 경험
- 단순히 "어느 지점에 도달하는 것"이 목적이 아님 — 걷는 과정이 목적

Place 요소:
- 각 전망대(굴등, 갈바람통, 매봉, 사다리통, 막개)는 독립 체류 지점
- 각 마을(함구미, 직포, 학동 등)은 별도 장소 기능 (식사, 숙박)

종합 판단:

▎ 비렁길은 Route를 따라 이동하면서 Movement Experience를 경험하는 구조이며, 중간 마을과 전망대는 Place 요소로 분리된다. 이 세 가지를 하나의 "비렁길"로 단일 Entity화하는 것은 오류다.
