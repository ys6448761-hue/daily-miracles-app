# CAND-WISH-001 — DreamTown Happy Memory First Principle

## Purpose

DreamTown 소원그림은 여수 관광 이미지를 생성하는 프로젝트가 아니다.

소원이가 자신의 **가장 행복했던 기억 속의 나**를 다시 만나게 하는
희망 복원 시스템을 구축하기 위한 원칙이다.

## Core Definition

DreamTown Wish Art의 가장 중요한 목적은 "아름다운 여수를 보여주는
것"이 아니라 **"가장 행복했던 나를 다시 만나게 하는 것"**이다.

여수는 그 기억을 담아내는 무대이며, 주인공은 언제나 소원이다.

> **기존 원칙과의 관계(대표님 지시 반영):** 이 정의는 `SSOT-WISHART-001` §④
> Identity Lock의 검수 기준 "컨디션 좋던 시절처럼 보이나"를
> **철학적으로 확장한 개념**이다. 새로운 원칙을 발명한 것이 아니라,
> 이미 있던 기준의 의미를 더 분명하게 설명한 것이며 기존 SSOT와
> 충돌하지 않는다.

## First Principle

이미지를 평가할 때 가장 먼저 확인해야 하는 것은 "여수가 아름다운가?"가
아니다.

반드시 다음 순서를 따른다.

1. 이 사람이 본인처럼 보이는가?
2. 가장 행복했던 나의 표정이 살아있는가?
3. 자연스러운 미소가 복원되었는가?
4. 여수가 그 감정을 더 잘 표현하는가?

여수는 감정을 강화하는 배경이다. 감정보다 앞설 수 없다.

## DreamTown Wish Formula

```
행복했던 나
  +
자연스러운 미소
  +
소원에 가장 잘 어울리는 여수 장소
  +
DreamTown 수채화 세계관
  =
소원그림
```

## Smile Principle (Identity Lock 하위 원칙)

> **구조 정정(대표님 지시 반영):** 이 원칙은 새로운 Lock이 아니다.
> `SSOT-WISHART-001` §④ Identity Lock의 **하위 원칙**으로 통합된다 —
> 기존의 "3대 Lock"(Identity / Location / World Response) 구조를
> 변경하지 않는다.

모든 소원그림은 사용자의 가장 행복했던 순간을 떠올릴 수 있는
자연스러운 미소를 반드시 포함한다.

**허용:**

- 편안한 입꼬리
- 눈웃음
- 따뜻한 시선
- 좋은 날의 표정

**금지:**

- 과장된 웃음
- 광고 모델 미소
- 치아를 과하게 드러낸 웃음
- SNS 포즈
- 억지 웃음

**검수 질문:** "이 표정을 보면 예전 행복했던 내가 떠오르는가?" NO이면
재생성한다.

## Emotion Before Location Rule

장소를 먼저 선택하지 않는다.

반드시 다음 순서로 결정한다.

```
소원
  ↓
감정
  ↓
행복했던 나
  ↓
가장 잘 어울리는 여수
```

## Yeosu Emotion Mapping

여수의 장소는 관광지가 아니라 감정을 표현하는 무대이다.

| 감정 | 장소 |
|---|---|
| 새출발 | 여수엑스포역 |
| 용기 | 여수해상케이블카 |
| 치유 | 오동도 |
| 감사 | 이순신광장 |
| 희망 | 하멜등대 |
| 사랑 | 미남크루즈 |
| 쉼 | 종포해양공원 |

향후 장소가 추가되어도 반드시 "이 장소는 어떤 감정을 상징하는가?"를
먼저 정의한다.

> **기존 체계와의 관계(대표님 지시 반영):** `SSOT-WISHART-001` §⑤
> Emotion Rule은 이미 **보석/별 종류별** 표정 키(예: 치유의별=subtle
> smile of relief, 새출발의별=resolved calm gaze)를 정의하고 있다.
> 두 체계는 **서로 다른 축**을 담당한다 —
> **보석별 Emotion Rule = 표정과 감정**을 결정하고,
> **Yeosu Emotion Mapping(장소) = 배경과 무대**를 결정한다.
> 두 체계가 같은 감정 단어(치유, 새출발 등)를 공유하는 것은 의도된
> 일치이며, 중복이나 충돌이 아니다. 실제 적용 시 표정은 보석별
> Emotion Rule을 따르고, 배경/장소는 Yeosu Emotion Mapping을 따른다.

## Evaluation Rule

**성공:**

- "저때의 내가 생각난다."
- "예전의 나처럼 웃고 있다."
- "나도 저런 표정을 지었던 적이 있었지."

**실패:**

- "배경은 예쁜데 내가 아니다."
- "여수만 보인다."
- "그림은 예쁜데 감동이 없다."

## Conflict Check (2026-07-21)

- **`SSOT-WISHART-001` §④ Identity Lock** — "컨디션 좋던 시절처럼
  보이나"라는 기존 검수 기준과 본 문서의 Core Definition이 방향상
  일치한다. 대표님 지시에 따라 "확장" 관계로 명시했다(위 Core
  Definition 하단 인용 참조). 충돌 아님.
- **`SSOT-WISHART-001`의 "3대 Lock" 구조** — 본 문서가 처음
  제시했던 "Smile Lock(NEW LOCKED)"은 4번째 Lock을 암시해 기존 "3대
  Lock" 표현과 구조적으로 맞지 않았다. 대표님 지시에 따라 **Identity
  Lock의 하위 원칙(Smile Principle)으로 통합**했다 — 이제 구조
  충돌 없음.
- **`SSOT-WISHART-001` §⑤ Emotion Rule(보석별 표정 매핑)** — 본 문서의
  Yeosu Emotion Mapping(장소별)과 감정 단어를 일부 공유하나, 대표님
  지시에 따라 "표정=보석별 / 배경·무대=장소별"로 축을 명확히
  구분했다. 중복 아님.
- **`SSOT-IMG-001`의 기존 "작은 미소" 가이드** — 본 문서의 Smile
  Principle이 이를 더 구체화한 것으로, 충돌 아님.
- **즉시 적용 여부** — 원안의 "Claude Code Action"(모든 프롬프트
  생성에 즉시 강제 적용)은 Candidate 단계 성격과 맞지 않아 제거하고,
  "향후 SSOT-WISHART 개정 시 검토 대상"으로 수정했다(위 Future
  Consideration 참조).
