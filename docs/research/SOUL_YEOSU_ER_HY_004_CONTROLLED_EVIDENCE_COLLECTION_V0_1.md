## §6. Pattern Summary

**Rest Point Pattern — Stair Route:**
- No designated benches or seating on the ascent stair route (4 independent WE sources)
- Continuous stair climbing described; natural micro-pauses possible at stone gate junctions (7 gates force sequential single-file passage creating brief pauses)
- Ascent described as demanding: "숨이 찰 무렵" (when breath becomes labored), "숨이 턱 끝까지 차오르고" (breath reaches throat)
- NO formal rest infrastructure documented

**Rest Available AFTER Ascent:**
- Within temple compound (경내): shaded areas; can sit quietly (EI-HY-004-B)
- Temple compound provides the primary structured rest opportunity in the visit

**Rest on Flat Route:**
- Flat alternative path (평지길): gentler slope allows informal pausing
- No formal infrastructure; terrain-enabled informal rest

**Summary for H-2 Judgment:**
- Stair route: no mid-ascent rest stops; demanding continuous climb; rest available only at top
- Flat route: more natural pacing; informal pauses easier; same temple access
- For elder/mobility-concerned travelers: flat route provides more resting flexibility without formal rest stops
