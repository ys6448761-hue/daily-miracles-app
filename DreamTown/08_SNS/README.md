# 08_SNS — SNS 운영

---

**목적:** DreamTown 콘텐츠의 SNS(인스타그램 등) 배포/운영 기록.
**역할:** Operations (운영) — 제작(Production)은 여기서 하지 않는다.

## 절대 원칙 — 영상/이미지 중복 저장 금지

**이 폴더에는 영상·이미지 원본을 저장하지 않는다.** 원본은 항상
`dreamtown-assets/05_FINAL`(영상), `dreamtown-assets/02_IMAGE`(이미지)를
참조한다.

이 폴더는 다음만 관리한다:

- 게시 기록(플랫폼, 게시일, 캡션, 참조 원본 경로)
- 캠페인/시리즈 구성
- 성과 지표(필요 시)

## AI Instructions

- 원본 자산을 복제하지 않는다 — 항상 `dreamtown-assets`를 참조한다.
- 게시 기록은 실제 게시 이후에만 기록한다.
